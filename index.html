About Me

Flutter and Android apps, and the web systems behind them.

I'm W.K.D. Kavishka (Dumindu Kavishka), a software engineer in Colombo, Sri Lanka. I build Flutter and native Android apps, and the web systems behind them.

At Ceylon Business Appliances I work on Android apps that run in the field: GPS tracking that keeps running in the background through Android's battery limits, locked-down kiosk phones, and launchers for payment terminals that talk to cash registers over TCP, USB and Bluetooth. I also built a full-stack inventory system there with Next.js, Spring Boot and PostgreSQL.

At Globevik I build backends for web platforms: Express APIs on PostgreSQL, PayHere payments and Docker deployments.

On my own I build web apps with Next.js, Chrome extensions and small Linux tools.
